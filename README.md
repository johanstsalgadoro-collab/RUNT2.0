# Presentación web — Parque automotor en Colombia

Presentación HTML/CSS/JS lista para GitHub Pages.

## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. Sube **todo el contenido** de la carpeta al repositorio, de modo que `index.html` quede en la raíz.
3. En GitHub abre `Settings > Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios.

## Navegación

- Flecha derecha / espacio: siguiente diapositiva.
- Flecha izquierda: diapositiva anterior.
- Home: primera diapositiva.
- End: última diapositiva.
- En móvil también funciona con gesto lateral.

## Archivos

- `index.html`: contenido de la presentación.
- `styles.css`: diseño y responsividad.
- `script.js`: navegación y animaciones.
- `assets/`: gráficas generadas en R.


## Vista completa de graficas

Todas las graficas pueden abrirse en un visor a pantalla completa haciendo clic sobre la imagen o en el boton **Ver completa**. Se cierra con la X, con la tecla Esc o haciendo clic fuera de la imagen.
